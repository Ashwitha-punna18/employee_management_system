# Employee Management System

## Project Description
A menu-driven Employee Management System developed using C programming.

This project helps manage employee records through a simple menu-based interface.

## Features
- Add Employee
- Display Employees
- Search Employee
- Update Employee
- Delete Employee
- Exit the Program

## Technologies Used
- C Programming
- Structures
- Functions
- File Handling

## How to Run

Compile the program:

```bash
gcc employee_management_system.c -o employee.exe
```

Run the program:

```bash
./employee.exe
```
